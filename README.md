# Verba → Sprigo

**Verba is archived. Development continues as [Sprigo](https://github.com/ozerozdas/sprigo).**

A local-first language-learning app for the desktop. Lessons, stories and
conversation practice are generated by an AI model running on your own machine.

**[→ github.com/ozerozdas/sprigo](https://github.com/ozerozdas/sprigo)** · **[→ mehmetozer.dev/sprigo](https://mehmetozer.dev/sprigo)**

</div>

---

This repository is read-only. No new releases, fixes or issues will land here.

- **New users:** go straight to [Sprigo](https://github.com/ozerozdas/sprigo).
- **Existing Verba users:** your data lives in a local SQLite file on your machine;
  nothing was ever stored on a server. Old builds remain available under
  [Releases](https://github.com/nuvocode/verba/releases) but will not be updated.

The code stays here under the [MIT license](./LICENSE) for reference.
